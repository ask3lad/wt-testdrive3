# Test Drive 3.0 | TD3 | wt-testdrive3

**Ask3lad Test Drive 3.0** sets up your own Ground, Naval, Air and Helicopter test drives in War Thunder in a few clicks. Pick a vehicle, loadout, targets, map and weather, press **Apply**, then load the mission from User Missions in game.

> The app is in alpha. Check the release notes for what is new in each update.

### Install

1. Download the **TestDrive3-Setup** exe from the [latest release](https://github.com/ask3lad/wt-testdrive3/releases/latest) and run it.
2. If SmartScreen appears, click **More Info**, then **Run Anyway**.
3. Pick your language, confirm your War Thunder folder and follow the short tour.

The app updates itself, so you only need to install it once.

Requires Windows 10 or 11 and War Thunder.
